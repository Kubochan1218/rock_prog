version2.0.0 リリースノート

2026-07-15 version2.0.0アップデート
【お願い】
・exeファイルに同梱されているファイルは、フォルダから移動したり削除したりしないでください。
・出席データが記録されているExcelファイル（.xslx）は、exeファイルと同じディレクトリ（フォルダ）に置くか、アプリの設定からパスを指定してください。

【アップデート概要】
・UIを大幅に刷新し、操作しやすくなりました。
・「ライブ管理」機能を追加し、ライブごとに日程・バンド情報などをまとめて管理できるようになりました。
・タイムテーブル作成時の自動保存機能を導入しました（保存作業が不要になりました）。
・出席データの書き込み形式を変更しました。
・ライブ情報・バンド情報・タイムテーブル情報を、ひとつの.jsonファイルに統合し、管理しやすくなりました。

【アップデート詳細】
1.UIの大幅更新
左側にサイドバーを追加し、メニューを集約しました。また、ホーム画面にはダッシュボードを表示し、さまざまな機能に直接アクセス可能になりました。

2.「ライブ管理」機能の追加
これまで、タイムテーブル作成時に都度設定していたライブ情報（日程・時間）を事前に設定できるようにしました。「ライブ管理」画面では、ライブ名・日時を設定することができ、タイムテーブル作成時も、ライブ名を選択することで、日程や時刻が自動で反映されます。
※本機能は「バンド登録」、「バンド選出」、「タイムテーブル作成」前に実行する必要があります。

3.「タイムテーブル」の自動保存機能の追加
タイムテーブル作成時に自動保存機能を追加しました。バンド枠や特別枠を追加・移動・削除すると、自動的に保存されます。また、タイムテーブル作成画面を開くと、保存されている情報が自動的に表示されます。従来の「保存」、「読み込み」操作が不要になりました。

4.出席データの書き込み形式の変更
Excelファイルへの出席データの書き込み形式を以下の通り変更し、目視で確認しやすくなったほか、○（漢数字）と○（記号）などの差異によって出席率計算に誤差が出る現象を修正しました。

変更前 | 変更後
　〇　 | 出　席
　△　 |連絡あり
　×　　|無断欠席
　オ　 | 　オ　 （※変更なし）
忌　引 | 忌　引 （※変更なし）

※なお、この変更によって、既存の出欠データを表のように書き換える必要があります。書き換えには、専用のツール（convert.exe）を使用してください。

5.ライブ情報・バンド情報・タイムテーブルの保存先の統一
これまで、出演バンドとタイムテーブル情報を別のファイルに保存していましたが、今回のアップデート以降はライブ情報と共に一つのファイルに保存するように変更しました。
